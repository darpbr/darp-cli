# Tasks Template

## Purpose

Break an approved implementation plan into small, reviewable execution steps.

## When to Use

Use this template immediately before implementation begins.

Every implementation task must be written as an unchecked Markdown checkbox
(`- [ ]`). The implementer marks it (`- [x]`) only after the task and its
validation are complete. Blocked tasks remain unchecked and must record the
reason.

## Expected Sections

1. Title
2. Related Plan
3. Task List
4. Validation Checklist
5. Notes and Assumptions

## Completion Criteria

- Tasks are small and independently understandable.
- Validation steps are attached to the work.
- Dependencies between tasks are explicit.
- Each task has a checkbox that can be updated during implementation.
- The list is ready to guide implementation and review.

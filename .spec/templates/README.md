# Template Library

This directory contains reusable templates for the planning artifacts required by the DARP Development Lifecycle.

## Contents

- Specification template
- ADR template
- Implementation plan template
- Tasks template

## Lifecycle Role

Use these templates to start new work consistently after the repository bootstrap is complete.

Create a feature directory under `.spec/specs/<number>-<short-name>/` and
copy the specification, implementation-plan, and tasks templates to
`spec.md`, `plan.md`, and `tasks.md` respectively.
